# Hotel Booking Management System (CLI)

Hi there! This is a simple Command Line Interface (CLI) application that I built to manage hotel room bookings. I created this project to practice my programming fundamentals, data logic, and handling user inputs.

## 🚀 Features
* **View Available Rooms:** Shows a list of all rooms that are currently free.
* **Book a Room:** Allows a user to book a room by entering the room number.
* **Cancel a Booking:** Frees up a room if a guest checks out or cancels by the room number.
* **Edge Case Handling:** Includes checks to make sure the app doesn't crash if you enter a wrong room number or an invalid input.

## 🛠️ Tech Stack & Concepts Used
* **Language:** Java
* **Data Storage:** ArrayLists to keep track of hotel room states.
* **Control Flow:** Loops (`for`), conditional statements (`if-else`), and user input scanners.

## 📦 How to Run the App
1. Clone this repository to your local machine.
2. Open the project in your favorite IDE (like IntelliJ IDEA, Android Studio, or VS Code).
3. Run the `Main` file.
4. Follow the instructions displayed in the terminal menu!

## 🧠 What I Learned / Challenges
* **Input Validation:** It was tricky at first to stop the app from crashing when typing a letter instead of a number, but I learned how to handle it!
* **List Management:** Learned how to loop through lists to find a specific room and update its booking status.
